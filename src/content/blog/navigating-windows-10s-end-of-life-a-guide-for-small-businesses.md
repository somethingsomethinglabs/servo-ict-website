> **Update, September 2026:** Standard support for Windows 10 ended on 14 October 2025. This guide now applies to businesses that still have Windows 10 devices in use.

Microsoft no longer provides standard security updates or technical support for Windows 10. A computer may keep working, but running unsupported software increases the chance that a newly discovered security problem will remain unfixed.

## What end of life means

End of life means the operating system no longer receives its normal updates, security patches or technical support. Unsupported devices can create security and reliability problems for the rest of a business network.

When this article was first published in February 2025, [StatCounter's Australian data](https://gs.statcounter.com/windows-version-market-share/desktop/australia/) showed that many computers still used Windows 10. That made early planning important. Businesses that have not completed the move should now treat it as current work.

## Check your Windows version

1. Open the Start menu.
2. Type `winver`.
3. Press Enter.

The window will show the version of Windows installed on that computer. Repeat the check on every business device rather than assuming they all run the same version.

## Check whether the device can run Windows 11

Not every Windows 10 computer meets the Windows 11 hardware requirements. Microsoft's [PC Health Check guidance](https://support.microsoft.com/en-us/windows/how-to-check-if-your-device-meets-windows-11-system-requirements-after-changing-device-hardware-f3bc0aeb-6884-41a1-ab57-88258df6812b) explains how to check compatibility.

If a device does not meet the requirements, decide whether to replace it, retire it or isolate it while you replace the software it supports. Do not leave an unsupported computer connected indefinitely without a plan.

## Prepare for the move

### Test important software

List the applications, printers and specialised equipment the business depends on. Test them on Windows 11 before changing every computer.

### Back up your data

Make a current backup of important files and confirm that you can restore it. Include data stored inside desktop applications, not only files in Documents or on the desktop.

### Plan the order

Move a low-risk computer first. Once the software, printers and sign-in process work, schedule the remaining devices in small groups. Keep one known-good option available while the change is underway.

## Upgrade or replace

Compatible computers can use Microsoft's [Windows 11 installation options](https://www.microsoft.com/en-au/software-download/windows11). Older computers may need replacement. Compare the cost of replacement with the time and risk involved in keeping an unsupported device working.
